# Aajaj DOOM

Мини-клон DOOM для Android. Классический raycasting-рендер 3D-мира, ходящие импы,
стрельба, HUD с хп/патронами/фрагами.

## Управление (touch)

- **Левая половина экрана** — виртуальный джойстик: ходьба вперёд/назад и стрейф.
- **Правая половина экрана** — свайп горизонтально, чтобы поворачивать камеру.
- **Кнопка FIRE** (правый нижний угол) — выстрел. Патроны ограничены.
- При смерти (HP = 0) через пару секунд уровень перезапустится.

## Как это устроено

- `DoomView` — кастомный `SurfaceView` с фиксированным внутренним разрешением
  320×180, картинка масштабируется на экран. Такой «ретро»-вид плюс лёгкий FPS.
- Для каждого столбца экрана кидается DDA-луч по сетке стен, затем рисуются
  спрайты врагов с z-буфером.
- Выстрел — hit-scan: из позиции игрока по `dir` ищем ближайшего врага в
  пределах расстояния до стены.
- Враги идут к игроку по прямой видимости, толкают друг друга и бьют в упор.

## Как получить APK

В репозитории настроен GitHub Actions workflow (`.github/workflows/android.yml`),
который собирает debug-APK на каждый push.

1. Откройте вкладку **Actions** на GitHub.
2. Выберите последний успешный запуск *Build APK*.
3. В разделе **Artifacts** скачайте `Aajaj-debug-apk.zip`.
4. Распакуйте и установите `.apk` на Android-устройстве (нужно разрешить установку
   из неизвестных источников).

## Локальная сборка

Требуется Android SDK и JDK 17:

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Стек

- Kotlin, Android SDK 34, minSdk 21
- `SurfaceView` + собственный game loop (~60 FPS)
- Raycasting + спрайтовый рендер, всё рисуется в `IntArray` и потом
  переносится на `Bitmap`
- Gradle Kotlin DSL
