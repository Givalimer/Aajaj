# Aajaj School

Мобильная first-person horror-игра в духе Baldi's Basics, написанная с нуля на Kotlin + Android SDK. Без движков — весь рендер делает кастомный raycaster.

## Геймплей
- Ты попал в школу-лабиринт.
- На карте разбросано 5 **тетрадей**. Подбирая каждую, ты решаешь математический пример (3 варианта ответа).
- За тобой гоняется **учитель**. Он ищет тебя по лабиринту через BFS.
- **Неправильный ответ** в тетради ускоряет учителя.
- Собери все тетради и дойди до зелёного **выхода** — ты сбежал.
- Учитель коснулся тебя — game over.

## Управление (сенсорное)
- **Левая половина экрана**: виртуальный джойстик движения (вперёд/назад/боком).
- **Правая половина экрана**: поворот камеры.
- На миникарте в углу: синяя точка — ты, красная — учитель, жёлтые — тетради, зелёная — выход.

## Архитектура
```
app/src/main/java/com/givalimer/aajaj/
├── MainActivity.kt   — активити, диалоги математики / победы / поражения
├── GameView.kt       — SurfaceView: game loop, raycasting, ввод, HUD
├── World.kt          — генерация лабиринта со стенами, тетрадями и выходом
├── Teacher.kt        — BFS-поиск пути и движение преследователя
└── MathProblem.kt    — генератор математических задач
```

## Как получить APK
Workflow `.github/workflows/android.yml` собирает debug-APK на каждый push.
1. GitHub → **Actions** → последний прогон **Build APK**.
2. Раздел **Artifacts** → скачай `Aajaj-debug-apk.zip`.
3. Распакуй → `app-debug.apk` → установи на Android.

## Локальная сборка
Нужен JDK 17 и Android SDK (platform 34):
```bash
./gradlew :app:assembleDebug
```
APK появится в `app/build/outputs/apk/debug/`.
