# Aajaj Sandbox

Простая Android-игра-песочница в стиле *falling sand*.

Тапай по экрану — и в мир сыпется песок, льётся вода, ставится камень или стирается всё подряд. Физика падения и перетекания работает на простой клеточной автоматной модели (~60 FPS).

## Инструменты
- **Песок** — сыплется вниз, образует кучки.
- **Вода** — течёт вниз и в стороны, песок через неё тонет.
- **Камень** — статичный, стены/платформы.
- **Стёрка** — удаляет материал.
- **Очистить** — очистка всего мира.

## Как получить APK

В этом репозитории настроен GitHub Actions workflow (`.github/workflows/android.yml`),
который собирает debug-APK на каждый push.

1. Открой вкладку **Actions** на GitHub.
2. Выбери последний успешный запуск *Build APK*.
3. В разделе **Artifacts** скачай `Aajaj-debug-apk.zip`.
4. Распакуй и установи `.apk` на Android-устройстве (нужно разрешить установку из неизвестных источников).

## Локальная сборка

Требуется Android SDK и JDK 17:

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Стек
- Kotlin
- Android SDK 34, minSdk 21
- `SurfaceView` + кастомный game loop
