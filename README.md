# Pixel Alchemy

Реалистичная Android-песочница в стиле *falling sand* с 16 материалами, химическими реакциями, огнём, живностью и процедурной графикой.

## Что можно

**Материалы:**
- **Сыпучие:** песок, порох, сахар.
- **Жидкости:** вода, нефть, кислота, лава — каждая со своей плотностью (тяжёлое тонет, лёгкое всплывает).
- **Твёрдые:** камень, дерево, лёд, росток.
- **Газы:** огонь, дым, пар — поднимаются и со временем рассеиваются.
- **Живые:** муравей — бродит по миру, ищет сахар, гибнет в воде/кислоте/огне.
- **Мета:** стёрка.

**Реакции:**
- Вода тушит огонь → становится паром.
- Лава + вода → камень + пар.
- Лава или огонь поджигают дерево, растения, нефть, порох.
- Кислота разъедает дерево, растения, песок, сахар, лёд, муравьёв — сама при этом расходуется.
- Порох рядом с огнём/лавой → взрыв (огонь по радиусу).
- Лёд тает возле огня/лавы.
- Росток при поливе водой растёт вверх.
- Муравьи целенаправленно идут на сахар в радиусе 3 клеток.

**Физика:**
- Плотности: лава > сахар/порох/песок > вода > нефть > воздух; лёгкое всплывает в тяжёлом.
- Шестиклеточная окрестность, bottom-up симуляция, чередование направления обхода для избавления от дрейфа в одну сторону.
- Процедурная текстура: per-pixel шум для песка/воды/камня/дерева/кислоты, анимированные цвета для огня и лавы.

## Управление
- Тап или свайп по экрану — рисует выбранным материалом. Быстрые свайпы интерполируются, дырок в следе не будет.
- Слайдер **Размер кисти** сверху — радиус кругового мазка.
- Палитра внизу, прокрутка влево-вправо.
- Кнопка **Очистить** — сносит мир.

## Как получить APK

CI сам собирает debug-APK на каждый push. После пуша:
1. GitHub → **Actions** → последний успешный прогон **Build APK**.
2. Раздел **Artifacts** → `Aajaj-debug-apk.zip`.
3. Распакуй → установи `app-debug.apk` на Android.

## Локальная сборка
Нужен JDK 17 и Android SDK (platform 34):
```bash
./gradlew :app:assembleDebug
```
APK появится в `app/build/outputs/apk/debug/`.

## Архитектура
```
app/src/main/java/com/givalimer/aajaj/
├── MainActivity.kt   — Activity, собирает палитру и слайдер программно
├── SandboxView.kt    — SurfaceView: game loop, рендер в Bitmap, ввод
├── World.kt          — сетка клеток, правила материалов, реакции
└── Material.kt       — enum материалов с плотностью/флагами
```

Иконка приложения — адаптивная `res/drawable/ic_launcher_foreground.xml` (пробирка с каплями).
